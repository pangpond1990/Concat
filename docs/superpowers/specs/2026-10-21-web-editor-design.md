# PON Cut: local web interface for the Concat engine

The user requested a fork of jub0t/Concat usable through a web browser and chose use on this Mac first. The fork is pangpond1990/Concat. The implementation belongs on feat/web-editor.

Use the existing Concat engine through its headless MCP stdio protocol. Do not reimplement editing or export in JavaScript. The native Slint desktop UI cannot simply be served as a website. Add a Node 22 HTTP adapter and a browser editor in web/. Use a distinct name, PON Cut, and link the upstream and fork sources. Keep the original license and source intact.

Deliver a local editor at http://127.0.0.1:4317, with project creation/reopening, streamed media imports, multitrack timeline, selecting/moving/splitting/trimming/removing clips, titles, volume/speed/transform controls, undo/redo, saving, composited frame preview, rendered playback with audio, MP4 export with progress/cancellation/download. Offer portrait, landscape and square presets. UI text is Thai with familiar English editing terms.

The native engine owns project data and history. Each web project has a server-generated id and an isolated directory under web/data. Browser requests never choose filesystem paths. Saves follow successful edits. Export filenames are generated by the server. Imports are copies, leaving originals intact. Persist projects across restarts. One engine process serves requests; exports are background jobs. Use the released macOS ARM64 engine for local verification, with a configurable binary path for other installations.

The server binds loopback only. Reject untrusted Host and cross-origin requests, restrict media/downloads to the managed project, bound request/upload sizes and clean partial uploads. No cloud service or account is needed. This first version does not promise every desktop feature, automatic speech transcription, user accounts, or public hosting. Rendered playback may take preparation time and must show honest progress. No fake success states.

Implementation choices made by the agent: dependency-free Node and vanilla browser modules, port 4317, a dark editing workspace, default portrait 1080x1920 at 30 fps, upstream release 0.2.8. A launcher opens the local URL. Add setup/usage/limitations documentation and automated tests around the adapter, real engine edits, rendering and invalid requests.
